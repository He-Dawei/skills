# 非工具书 → 蒸作者的思维框架

非工具书 = 不教你具体怎么做，而是呈现一种看世界的方式（思想类、传记、散文、商业观察）。

**蒸作者的思维框架。** 目的：以后遇到问题，借他的角度想一遍。

注意区别：工具书给你**答案**，非工具书给你**提问的方式**。

## 判定特征

- 没有可执行的步骤清单
- 反复出现某些取舍倾向（比如总是先看长期、总是先看激励结构）
- 用大量案例说明同一个判断
- 读完你说不清「学会了什么」，但看问题的方式变了

## 抽取单元：三件套

```
核心公理：<作者默认成立、从不论证的前提>
取舍函数：<他在 A 与 B 之间怎么选，依据是什么>
判断模式：<反复出现的思考动作，至少 3 个实例支撑>
出处：<章节 / 页码>
```

## 三栏的抽法

**核心公理** —— 找作者从不辩护就直接用的前提。
例：「资产是往你口袋放钱的，负债是从你口袋掏钱的」—— 他默认这个二分法成立，全书不证。

**取舍函数** —— 找他在两难里怎么站队，以及站队的依据。
不是找他的结论，是找**得出那个结论的算法**。

**判断模式** —— 这是最难也最有价值的一栏，要求**至少 3 个实例**。
只有一个例子的是偶然，出现三次以上才是模式。每个模式要附实例出处。

## 硬约束

- **判断模式必须有 ≥3 个实例支撑。** 不足 3 个的单列为「疑似模式，证据不足」，不进正式产物。
- **不要美化。** 如果作者的框架有明显漏洞或前后矛盾，如实标注 `矛盾：第X章说A，第Y章说B`。
  vault 规则也是这个立场：发现矛盾时保留双方并标注来源，不静默覆盖。
- **区分作者的框架和你自己的发挥。** 你补的推论标 `推演（非原文）`，不要混进作者的框架里。

## 反模式

- ❌ 把作者的观点列表当成思维框架（观点是结果，框架是产出结果的算法）
- ❌ 抽出一堆金句（那是摘抄）
- ❌ 用现代概念重新包装作者的话（时代错置，会失真）
