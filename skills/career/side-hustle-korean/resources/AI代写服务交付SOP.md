# AI代写服务 — 标准化交付流程 (SOP)

## 核心原则

AI初稿 + 人工精修 = 质量保证。客户买的是精修后的结果，不是AI裸输出。

---

## 一、接单流程

### 1.1 收到咨询
```
回复模板:
"你好~需要什么类型的文案/内容？告诉我用途+字数+风格偏好，我给你报价和交付时间~"
```

### 1.2 需求确认清单
- [ ] 内容类型: 小红书/公众号/简历/PPT/脚本？
- [ ] 字数/页数
- [ ] 目标受众: 什么人看？
- [ ] 风格: 正式/活泼/专业/文艺？
- [ ] 关键词/核心信息: 必须包含什么？
- [ ] 参考: 有没有喜欢的对标内容？
- [ ] 交付时间

### 1.3 报价
- 小红书文案: 50元/篇
- 公众号文章: 100元/篇(2000字)
- 简历优化: 30-80元
- PPT代做: 100-500元
- 短视频脚本: 50-100元
- 修复/头像: 20-50元

---

## 二、AI生成阶段 (10-20分钟)

### 2.1 小红书文案 Prompt
```
你是专业小红书内容创作者。写一篇小红书笔记：

主题: [客户主题]
目标受众: [客户描述]
字数: 500-800字
风格: [亲切/干货/故事]感

要求:
1. 标题吸引点击（用数字/疑问/对比/情绪词）
2. 第一段是"钩子"（让人想继续看）
3. 正文有干货或真实感受
4. 3-5个分点，每点简洁有力
5. 结尾引导互动（点赞/收藏/评论）
6. 用emoji自然点缀，不堆砌
7. 口语化，像朋友聊天

输出: 标题+正文+推荐标签
```

### 2.2 简历优化 Prompt
```
你是专业HR/简历优化师。请优化以下简历：

原始简历:
[粘贴]

优化要求:
1. 每段经历用STAR法则重写（情境-任务-行动-结果）
2. 用具体数据替代模糊描述
3. 去掉"吃苦耐劳""勤奋好学"等空话
4. 针对[目标岗位]调整关键词
5. 保持一页纸，简洁有力

输出: 优化后的完整简历
```

### 2.3 公众号文章 Prompt
```
你是专业新媒体编辑。写一篇公众号文章：

主题: [客户主题]
字数: 1500-2000字
定位: [行业/受众]

要求:
1. 标题3选1（不同角度）
2. 开头: 场景/故事/数据引入
3. 正文: 3-4段，每段小标题+案例
4. 结尾: 总结+金句
5. 文风: [根据客户要求]
```

---

## 三、人工精修阶段 (10-15分钟)

### 3.1 必检清单
- [ ] 去掉AI感: "总的来说""值得一提的是""此外"→删
- [ ] 加人情味: 加1-2句个人感受/真实细节
- [ ] 改长句: 超过30字的句子拆短
- [ ] 加emoji: 小红书每条加3-8个emoji
- [ ] 检查事实: 数据/人名/时间是否准确
- [ ] 检查敏感词: 小红书/公众号违规词
- [ ] 通读一遍: 像不像真人写的？

### 3.2 AI感词汇黑洞（必删）
"在这个XX的时代" "总的来说" "值得一提的是" "不可否认"
"众所周知" "随着XX的发展" "综上所述" "此外" "而且"
"具有重要意义" "不可或缺" "扮演着重要角色"

→ 这些词=AI写的=客户一眼看出来=差评

### 3.3 加人味技巧
- 加1个个人经历（"我之前也遇到过..."）
- 加1个真实数据
- 加1处自嘲/幽默
- 加口语化表达（"说实话""真的""绝了"）

---

## 四、交付

### 4.1 交付消息模板
```
[客户名]，文案写好啦~

关键词: [客户关键词]
字数: [XX]字
风格: [XX风格]

你看看风格和内容可以吗？有需要调整的地方告诉我，免费修改~
```

### 4.2 修改处理
- 小改(<30%内容): 免费，1小时内
- 大改(>30%): 加收50%
- 客户不满意: 全额退款（极少发生，先发AI初稿确认方向）

---

## 五、质量管理

### 5.1 绝不交付的情况
- 纯AI输出未经人工检查
- 有事实错误
- 读起来"不像人写的"
- 超过约定时间未交付

### 5.2 效率指标
- 小红书文案: 30分钟/篇（AI 15min + 精修 15min）
- 简历优化: 20分钟/份
- 公众号文章: 45分钟/篇
- PPT: 1-2小时/套
- 修复/头像: 15分钟/张

---

## 六、客户复购技巧

1. 首次交付附带小赠品: "送你5个小红书爆款标题模板"
2. 3天后主动问: "上次的文案发布了吗？数据怎么样？"
3. 老客户9折: "老客户下次9折"
4. 节假日问候: 春节/端午/中秋发消息
