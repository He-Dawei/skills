## 第三步: 推广渠道和方法

### 渠道1: 朋友圈 (最快，最稳)

文案模板：
```
推荐两个超好用的APP！

抖音极速版——刷视频还能赚钱，我试了真的能提现！
小红书——最近发现上面干货超多，学做菜/穿搭/职场全都有

点我的链接下载，新用户有专属福利👇
[你的推广链接]
```

每天发1-2条，不要刷屏。配一张APP截图更有说服力。

### 渠道2: 微信群/QQ群

话术模板：
```
家人们！分享一个羊毛🦙

抖音极速版新用户有30元红包，我已经提现了。
没用过的同学可以试试，白嫖不要钱~

[你的推广链接]

PS：是真的，我提现截图放下面了👇
```

发之前截图你的提现记录，增加可信度。

### 渠道3: 小红书笔记 (长尾流量)

标题例：
```
"学生党必装！这5个APP用了3年没删"
"2026年最值得下载的APP，第3个我天天用"
"刚发现小红书还能这样用！隐藏功能分享"
```

内容=真诚推荐+植入自己的推广链接(放在评论区)。

⚠️ 小红书不要直接说"拉新""推广"，会判违规。
说"推荐""分享""好用"就可以。

### 渠道4: 同学互推

大学里直接面对面推广，转化率最高。
- 食堂排队：给旁边同学看APP
- 宿舍串门：直接帮他们下载
- 班级群：分享链接+发红包(2块钱发10个包)

## 关键提醒

1. 用真人的方式推荐——不要说"帮我下载""完成任务"，说"这个APP真的好用"
