# 论文 / 报告 → 蒸论证链 + 可复用方法

**蒸两样东西**：作者的论证链（怎么从证据走到结论），以及可迁移的方法。
目的：复用他的方法与证据标准，而不是复用他的结论 —— 结论会过期，方法不会。

## 判定特征

- 有摘要 / 引言 / 方法 / 结果 / 讨论的骨架
- 有数据、图表、实验设计
- 有「本文的贡献」这类自陈
- 结论有明确的适用范围限定

## 抽取单元

```
主张：<一句话说清他主张什么>
证据：<支撑它的数据 / 实验 / 案例，含样本量或规模>
反驳与回应：<作者自己承认的弱点，以及怎么挡回去的>
可复用方法：<换个场景还能用的做法>
适用边界：<作者声明的适用范围；没声明就标「未声明」>
出处：<章节 / 页码 / 图表号>
```

## 关键：抽方法不抽结论

论文的价值随时间衰减 —— 结论会被后续研究推翻，方法不会。

**优先抽这些：**

- 实验设计（怎么控制变量、怎么选样本）
- 度量方式（怎么定义和测量关键量）
- 消融/对照的组织方式
- 数据处理与清洗的具体做法

**结论只作一句话记录**，不要展开。展开结论等于把过期的部分做得最厚。

## 「反驳与回应」这一栏

论文里这块通常在 Limitations / Discussion 章节。
作者自己承认的弱点往往是最诚实也最有用的信息 —— 它告诉你这个结论在什么条件下不成立。

如果作者没写 limitations，标 `未声明`，不要替他找。

## 多篇同主题时

若一次蒸多篇同主题论文：
1. 先各自抽单元
2. 再比对照 —— 哪些结论一致（可信度高）、哪些冲突（标出来，不要挑一边）
3. vault 规则：冲突时保留双方并注明来源

## 反模式

- ❌ 把摘要扩写成一篇长文（那是复述）
- ❌ 只抽结论，丢掉方法与边界（那是最容易过期的部分）
- ❌ 忽略 limitations 章节
